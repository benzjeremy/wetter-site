2. Keine Tracker, keine Werbenetze, keine Cookies 2. Zero Trackers, Zero Ad Networks, Zero Cookies

• Keine Cookies: Weder Session- noch Third-Party-Tracking-Cookies werden gesetzt.

• No Cookies: Neither session nor third-party tracking cookies are deployed.

• Keine Telemetrie: Kein Google Analytics, Firebase, Sentry oder sonstige Analysedienste.

• No Telemetry: Zero Google Analytics, Firebase, Sentry, or third-party analysis services.

• Local Storage: Selected locations and preferred units remain strictly local within the browser (localStorage) or private app SharedPreferences.

3. Wetterdaten-Abfrage via Open-Meteo REST API 3. Weather Queries via Open-Meteo REST API

Sowohl die Web-Applikation als auch die native Android-App fragen Wetter- und Geocoding-Daten direkt via verschlüsseltem HTTPS von den Servern von api.open-meteo.com bzw. geocoding-api.open-meteo.com ab. Es existieren keinerlei zwischengeschaltete Relay-Server von Jeremy Benz. Bei der HTTPS-Abfrage wird technisch bedingt Ihre IP-Adresse an Open-Meteo übermittelt, um die Daten auszuliefern. Open-Meteo unterliegt strengen europäischen Datenschutzstandards.

Both the web application and the native Android app retrieve weather and geocoding metrics directly via encrypted HTTPS from api.open-meteo.com and geocoding-api.open-meteo.com. There are zero intermediate relay servers operated by Jeremy Benz. Technical IP transmission occurs directly to Open-Meteo strictly to fulfill data delivery. Open-Meteo complies with European privacy frameworks.

4. Rechte der Nutzer (Art. 15–21 DSGVO) 4. User Rights (Arts. 15–21 GDPR)

Sie haben das Recht auf Auskunft (Art. 15), Berichtigung (Art. 16) und Löschung (Art. 17). Da wetter-site auf den eigenen Servern keinerlei personenbezogene Daten speichert, können Sie alle lokalen Einstellungen jederzeit durch Leeren des Browser-Caches bzw. Zurücksetzen der App-Daten vollständig und sofort löschen.

You have full rights to access (Art. 15), rectification (Art. 16), and erasure (Art. 17). Because wetter-site stores zero personal data on its servers, clearing your browser cache or clearing app data instantly purges all local configurations.
